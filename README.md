# Caldmere Downloads

The playable Caldmere demo and its launcher.

## What to download

- **CaldmereLauncher-0.1.0.zip** — the launcher (about 63 MB). Unzip it anywhere, run `CaldmereLauncher.exe`, and sign in with the same account you made on the Caldmere website. The launcher starts the game for you.
- **Caldmere-Demo-0.1.0.zip** — the full game demo on its own (about 1.2 GB). Unzip it and run `Caldmere.exe`.

## You need an account

Make your free account and your character first at the Caldmere website, then sign in inside the launcher or the game with that same account. Your website characters are your game characters — they live in the same place.

Windows 10 or 11, 64-bit. About 3 GB of free disk space for the game.
